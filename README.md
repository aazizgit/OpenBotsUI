# Магнит Плюс — Mini App concept v3

## Что изменено
- Верхняя панель соответствует концепту: профиль слева, логотип по центру, колокольчик сообщений справа. Поле поиска удалено.
- Заголовки секций, ссылки «Все ›», подписи, цены, кнопки, значки и отступы сделаны HTML/CSS, а не частью картинок.
- QR-код сделан отдельным векторным SVG и остаётся чётким на современных экранах. Это декоративный демонстрационный QR, не рабочий код лояльности.
- Визуальные изображения выделены в отдельные файлы в `assets/`, чтобы их можно было заменить URL-адресами вашего CDN.
- Шрифт Manrope — бесплатный, подключается из Google Fonts. При недоступности сети используется системный sans-serif.
- Адаптивная верстка с safe-area отступами и закреплённым нижним меню.

## Файлы
- `index.html` — структура и текстовый контент.
- `styles.css` — внешний вид, иконки SVG, отступы и адаптивность.
- `app.js` — демо-поведение кнопок, вкладок и избранного.
- `assets/` — иллюстрации и `qr-demo.svg`.

## Локальный запуск
Откройте `index.html` или запустите `python -m http.server 8000` и перейдите на `http://localhost:8000`.

## Публикация
Загрузите содержимое папки проекта в репозиторий GitHub и включите Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Подключение картинок с сервера
Пути к иллюстрациям находятся в `index.html`, например `src="assets/promo-art.png"`. Замените их на URL вашего сервера/CDN. Не заменяйте `qr-demo.svg` настоящим QR, пока не будет готова интеграция с backend.
